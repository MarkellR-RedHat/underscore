# Catalog license: CC0 1.0 Universal

The code in this repository is MIT licensed (see LICENSE).

**Every audio file produced by this pipeline, and every track in the published
Underscore catalog, is dedicated to the public domain under CC0 1.0.**

That means you can use the music in any video, commercial or not, with no
attribution, no fees, and no permission. Full text:
https://creativecommons.org/publicdomain/zero/1.0/legalcode

Why CC0 and not CC-BY: the tracks are generated from code written with the
help of a language model. The copyright status of machine-assisted works is
unsettled. Dedicating the output to the public domain removes that question
for everyone who uses it. Each track ships with its source code, its seed,
and its measurements, so anyone can regenerate or modify it.
